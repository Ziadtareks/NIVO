## Rules for acceptance

- A fixture proves application protocol/state behavior, not live AI capability.
- A catalog entry or zero price in metadata does not establish successful vision, search, or permanent free access.
- Live image requests may use only the explicitly configured vision model or a dedicated vision fallback; never the text fallback.
- User data/clipboard are not test fixtures. Tests use isolated stores and synthetic clipboard inputs.
- A requirement stays open until its stated evidence exists. External credentials and untested hardware are recorded explicitly.
